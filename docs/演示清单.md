# 效果演示清单

1. 启动桌面应用，确认服务状态为“在线”、检测器为 `YOLO11-face + PFLD (ONNX)`、设备为 CPU 或 CUDA。
2. 批量选择正常、闭眼、张嘴和低头图片，展示卡片结果与历史记录。
3. 上传一段驾驶视频，等待完成并展示抽样帧数和最高风险等级。
4. 启动摄像头，依次演示正常、闭眼、张嘴和低头；持续触发重度状态后展示告警。
5. 打开历史记录，确认时间、来源、文件、等级和分值已保存。
6. 关闭应用，通过任务管理器确认 Electron 与 `fatigue-server.exe` 均退出。
7. 备用演示：执行 `docker compose up`，浏览器打开 `http://localhost:5001`。
