# 效果演示清单

1. 安装并启动 Windows 桌面应用，确认首页显示“系统运行正常”和 CPU/CUDA 设备状态，界面不出现开发模式或模型实现字段。
2. 在“检测中心 / 批量图片”选择正常、闭眼、张嘴和低头图片，展示标注结果、疲劳等级、风险分值和三项行为指标。
3. 在“视频分析”上传驾驶视频，观察处理画面持续变化、帧索引连续增长、进度和视频时间更新；完成后记录处理总帧、平均 FPS 和单帧延迟。
4. 在“实时监测”启动摄像头，依次演示正常、闭眼、张嘴和低头；持续触发重度状态后展示安全预警。
5. 打开“分析中心”，展示等级、行为、来源、任务趋势和指标趋势图；进入视频详情查看逐帧时间线。
6. 分别演示 CSV 数据导出、单张/全部 PNG 图表导出，以及“打印 / PDF”保存报告。
7. 打开“历史记录”，按等级筛选并确认时间、来源、文件、等级和分值已保存。
8. 正常关闭应用，通过任务管理器确认桌面窗口及后台服务均退出。
9. 附加演示：执行 `docker compose up --build`，浏览器访问 `http://localhost:5001`。
