# 交付说明

## 系统功能

- 批量图片：同时选择多张图片，逐张显示标注画面、疲劳等级、风险分值和 EAR/MAR/俯仰角。
- 视频分析：依次检测源视频的每一个可解码帧，连续显示处理后的画面、帧进度、视频时间、行为指标、处理帧率和延迟；完成后自动保存实验数据。
- 实时监测：调用本机摄像头，持续显示标注结果；检测到重度疲劳时弹出安全预警。
- 分析中心：展示任务数、疲劳检出率、四级风险分布、闭眼/哈欠/低头次数、输入来源、每日趋势、指标趋势和视频实验表。
- 历史记录：本地 SQLite 保存图片与视频结果，可按等级筛选。
- 数据导出：历史数据导出为 CSV；每张图表或全部图表导出为 PNG；“打印 / PDF”通过系统打印窗口保存分析报告。

## 使用方法

Windows 主验收运行 `release/` 中的安装包。安装后从桌面快捷方式启动，进入“检测中心”选择图片、视频或摄像头。首次使用摄像头时需允许系统权限。CPU 可直接运行；环境中存在可用 CUDA Provider 时会自动使用 GPU。

Docker 是附加部署方式：执行 `docker compose up --build` 后访问 `http://localhost:5001`。Docker 适合图片和视频上传，摄像头透传取决于宿主环境。

## 判定与统计口径

系统根据闭眼、哈欠、低头的持续时间和 60 秒窗口内频次划分正常、轻度、中度、重度。静态图片只反映当前帧；视频和摄像头使用独立时序会话。视频实验表中的 FPS、延迟、处理帧数、行为次数和预警次数均来自实际运行。

“疲劳检出率”表示最终等级为轻度及以上的任务占全部任务的比例，不等同于有标注真值的识别准确率。当前交付不提供 mAP、Precision、Recall、训练曲线或消融实验；如需这些指标，必须另行准备标注测试集并执行标准评估。

## 运行边界

本系统用于项目演示和实验分析，不是车规级安全设备。低照度、遮挡、强侧脸、摄像头模糊会影响检测结果。疲劳阈值可根据验收素材、摄像头角度和驾驶姿态继续标定。
