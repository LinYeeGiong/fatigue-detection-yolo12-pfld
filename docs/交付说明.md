# 交付说明

## 系统简介

系统面向本地驾驶员疲劳行为演示，使用 YOLO11-face 定位人脸、PFLD 输出 98 个人脸关键点与头部姿态，再通过 EAR、MAR、Pitch 和时间窗口判定闭眼、哈欠、低头及疲劳等级。已有权重直接用于推理，没有重新训练。

## 功能

- 批量图片：多选图片并逐张显示疲劳等级、分值、EAR、MAR。
- 视频分析：上传视频后按帧率抽样，汇总最高风险等级和行为。
- 实时监测：调用本机摄像头，每 500 ms 分析一帧，重度疲劳显示弹窗。
- 历史记录：本地 SQLite 保存图片和视频任务结果。
- 运行设备：优先使用可用 CUDA Provider，否则自动使用 CPU。

## 使用方法

Windows 用户运行安装包，安装后从桌面快捷方式启动。首次打开需允许摄像头权限。Docker 用户执行 `docker compose up --build` 后访问 `http://localhost:5001`；Docker 主要适用于图片和视频上传，Windows 容器环境不保证摄像头透传。

## 判定规则

连续闭眼 2 秒进入轻度、3 秒进入中度、4 秒进入重度；持续低头分别为 2、4、6 秒；60 秒内哈欠 3 次为轻度、4 次为重度。阈值可根据实际摄像头、驾驶姿态和验收素材继续标定。

## 限制

本系统不是车规级安全设备。静态图片无法体现持续时长，只按当前行为给出正常、轻度或中度结果；视频与摄像头才进行时序判定。测试报告应使用实际标注素材计算案例识别率和 FPS，不应虚构 mAP、训练曲线或消融实验。
